# Инструкция по запуску автотестов Playwright

Данный проект содержит автоматизированные end-to-end тесты, написанные с использованием фреймворка [Playwright](https://playwright.dev/).

## Подготовка к запуску 

Перед локальным запуском тестов убедитесь, что у вас установлены все необходимые зависимости:
```bash
npm install
npx playwright install --with-deps
```

## Запуск автотестов

### 🎬 Запуск Сценария 1 (Для демонстрации)
Этот сценарий требует авторизации (или выполняется с логикой работы с лайками) и предназначен для визуальной демонстрации (в окне браузера).
Для запуска введите команду:
```bash
npx playwright test tests/scenario1.spec.ts --headed
```
*Флаг `--headed` используется, чтобы браузер открылся визуально поверх окон.*

### 🤖 Запуск Сценария 2 (Headless)
Сценарий для CI (выполняется в фоновом режиме, без авторизации). По итогу работы скрипт сохраняет артефакты (скриншот `screenshot.png` и структуру страницы `page.html`) в папку `artifacts/`. 
Запуск команды:
```bash
npx playwright test tests/scenario2.spec.ts
```
*Примечание: Если при запуске второго сценария сервер недоступен, вы можете использовать флаг предварительного старта локального сервера (настроенный ранее): `USE_LOCAL_SERVER=true npx playwright test tests/scenario2.spec.ts`*

## 🚀 Запуск пайплайна в GitHub Actions (CI)

Workflow настроен в файле `.github/workflows/playwright.yml`. Тесты прогоняются автоматически на события `push` и `pull_request` в основные ветки.

Так как в файле прописано правило `workflow_dispatch`, вы можете запустить процесс тестирования **вручную**:

1. Откройте ваш репозиторий на сайте **GitHub**.
2. Перейдите во вкладку **Actions** (в верхней панели).
3. В левом боковом меню (в разделе *All workflows*) выберите **Playwright Tests**.
4. С правой стороны появится небольшое уведомление с кнопкой **Run workflow**. Нажмите на неё.
5. Выберите нужную ветку (`master`) и нажмите на зеленую кнопку **Run workflow**, чтобы запустить пайплайн.

### Как получить артефакты из CI

После того как пайплайн успешно (или с ошибкой) завершит выполнение:
1. Кликните на этот запуск (run) в общем списке (вкладка Actions).
2. Прокрутите страницу вниз до раздела **Artifacts** (на странице Summary).
3. Там будет находиться архив **`scenario-2-artifacts`**, доступный для скачивания. Внутри этого архива лежат сгенерированные в `headless` режиме `screenshot.png` и `page.html`.
